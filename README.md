# Instagram-style UI demo

A responsive, front-end social feed inspired by familiar photo-sharing app patterns. This is an independent educational demo and is not affiliated with, endorsed by, or connected to Instagram or Meta.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For the best local development experience, open the folder in VS Code and use Live Server.

## Included
- Responsive desktop sidebar and mobile bottom navigation
- Stories row
- Feed cards with demo photos, likes, comments and save/share interactions
- Suggested accounts with follow-state interaction
- Explore grid and demo navigation views

## Important
This project intentionally does not include a real Instagram login, password collection, credential storage, or an admin panel for collecting Instagram credentials. All profiles and interactions are fictional front-end demo content. Photos and fonts load from third-party image/font CDNs, so an internet connection is needed for those assets.

## Customize
- Edit sample profiles and posts in `app.js`.
- Change layout and styling in `style.css`.
- Change page structure in `index.html`.
